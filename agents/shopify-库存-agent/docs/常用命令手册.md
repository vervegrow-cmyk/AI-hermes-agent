# Shopify 库存 Agent 日常命令手册

## 1. Dekuch 商品真实同步命令

这条命令已经列入日常命令手册，适合日常正式执行。

```powershell
chcp 65001
$env:PYTHONIOENCODING="utf-8"
python D:\桌面文件下载\AI-hermes-agent\agents\shopify-库存-agent\workflow\run_inventory_sync_cli.py --store-name 4ea863-98.myshopify.com --mode apply --shopify-query "vendor:Dekuch"
```

## 2. 命令作用

这条命令会对 Shopify 店铺 `4ea863-98.myshopify.com` 中 `vendor=Dekuch` 的商品执行一次真实同步任务。

它不是预演，而是会真实修改 Shopify 数据。

## 3. 命令能力

这条命令当前具备以下能力：

- 验证 Shopify 连接是否可用。
- 验证 Giga OpenAPI 连接是否可用。
- 扫描 Shopify 中 `vendor:Dekuch` 的商品变体。
- 按 SKU 去 Giga 查询库存。
- 如果 Giga 库存和 Shopify 库存不一致，更新 Shopify 库存。
- 如果 Giga 库存和 Shopify 库存一致，跳过不更新。
- 如果 `Dekuch` 商品的 Giga 返回 `该 SKU 未加入 Saved Items，或当前没有备货库存`，把 Shopify 商品状态改成 `DRAFT`。
- 如果同步后的目标库存小于 `5`，把 Shopify 商品状态改成 `DRAFT`。
- 如果商品本身已经是 `DRAFT`，则不重复下架，只记录为已是草稿状态。
- 终端持续打印中文处理进度、结果和异常信息。
- 执行结束后输出任务报告、缺 SKU 清单、重试清单。

## 4. 参数说明

- `chcp 65001`
  把当前 PowerShell 终端切换到 UTF-8 编码，尽量减少中文乱码。

- `$env:PYTHONIOENCODING="utf-8"`
  让 Python 标准输出使用 UTF-8 编码。

- `python ...run_inventory_sync_cli.py`
  启动库存同步 CLI。

- `--store-name 4ea863-98.myshopify.com`
  指定要操作的 Shopify 店铺。

- `--mode apply`
  真实执行模式。会真的更新库存，也会真的把商品改成草稿。

- `--shopify-query "vendor:Dekuch"`
  只处理 Shopify 中厂商为 `Dekuch` 的商品。

## 5. 常见结果说明

- `结果=skipped`
  这条记录本次未执行修改。
  常见原因：SKU 为空、库存一致、商品已是草稿、SKU 重复。

- `结果=updated`
  这条记录本次执行成功。
  可能是库存已更新，也可能是商品已改为 `DRAFT`。

- `动作=delist_product`
  表示本次执行的是“把商品状态改为草稿”。

- `动作=update_inventory_and_delist`
  表示本次先更新库存，再把商品状态改为草稿。

- `结果=failed`
  这条记录执行失败。
  常见原因：Giga 限流、接口异常、Shopify 更新失败。

## 6. 风险说明

- 这条命令会真实修改 Shopify 数据，不适合在不确认规则的情况下直接执行。
- 当前只处理 `vendor=Dekuch` 的商品，不会影响其他厂商商品。
- 当前 Giga 请求已做节流，但如果店铺商品量大，任务执行时间会比较长。

## 7. 建议用法

正式执行前，如果想先观察而不改数据，可以把 `--mode apply` 改成 `--mode dry-run`。

示例：

```powershell
chcp 65001
$env:PYTHONIOENCODING="utf-8"
python D:\桌面文件下载\AI-hermes-agent\agents\shopify-库存-agent\workflow\run_inventory_sync_cli.py --store-name 4ea863-98.myshopify.com --mode dry-run --shopify-query "vendor:Dekuch"
```
