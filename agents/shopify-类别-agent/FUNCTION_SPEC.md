# shopify-类别-agent 功能说明

## 一句话定义

基于 Shopify 商品编辑页中的类别、类别元字段和系统建议，结合 DeepSeek 大模型，对已上架商品进行批量类别纠偏与类别元字段补全的智能治理 agent。

## 功能目标

- 提高商品类别准确率
- 提高类别元字段完整率
- 降低人工逐品修正成本
- 建立可批量执行的商品分类治理流程
- 为搜索、筛选、推荐、广告 feed 和多渠道分发提供更高质量的数据基础

## 功能范围

### A. 类别诊断

- 检查当前商品是否已设置类别
- 检查当前类别是否与商品语义匹配
- 检查同类商品分类是否一致
- 检查类别是否足以触发正确的类别元字段模板

### B. 类别建议评估

- 读取 Shopify 后台建议类别
- 对比当前类别与建议类别
- 判断是否采用 Shopify 建议
- 判断是否需要 DeepSeek 二次裁决

### C. 类别元字段补全

- 读取当前类别对应的元字段模板
- 识别缺失项
- 从商品数据中推断可填写值
- 输出结构化候选字段值

### D. 批量应用

- 按单品执行
- 按产品集合执行
- 按供应商执行
- 按 Shopify query 执行

### E. 风险控制

- 高置信度自动应用
- 中置信度输出建议
- 低置信度进入人工复核

### F. 结果沉淀

- 记录原始值和建议值
- 记录模型说明
- 记录最终执行结果
- 生成批次报告

## 关键输入

- 商品标题
- 商品描述
- 商品图片
- Vendor
- Product Type
- Tags
- SKU
- 当前类别
- 当前类别元字段
- Shopify 建议类别和建议字段

## 关键输出

- 推荐类别
- 推荐元字段
- 风险等级
- 决策理由
- 是否自动应用
- 审计报告

## 成功标准

- 类别空值率下降
- 类别错配率下降
- 类别元字段完整率提升
- 人工逐品处理量下降
- 批量执行后低回滚率

## 不做的事

- 不直接替代商品文案生成
- 不直接替代价格和库存同步
- 不在低置信度情况下盲目覆盖现有类别
- 不跳过审计直接大规模写回
